# Project

- CLI-based BIST intraday stock advisor
- Same-day buy-at-open / sell-at-close workflow
- Uses end-of-day inputs
- Produces structured outputs, not natural-language advice
- Core commands: `import-daily-csv`, `daily`, `picks`, `review`
- Target: 5 to 10 daily stock picks
- Current workflow uses daily CSV snapshots as the main market-data source

## Core Strategy

- Short-term momentum
- Volume spikes
